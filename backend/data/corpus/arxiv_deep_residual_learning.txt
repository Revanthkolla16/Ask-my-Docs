Deep Residual Learning for Image Recognition
=============================================

Authors: Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun
Published: 2015 — arXiv:1512.03385
Venue: CVPR 2016 (Best Paper Award)


## Abstract

Deeper neural networks are more difficult to train. We present a residual learning framework to ease the training of networks that are substantially deeper than those used previously. We explicitly reformulate the layers as learning residual functions with reference to the layer inputs, instead of learning unreferenced functions. We provide comprehensive empirical evidence showing that these residual networks are easier to optimize, and can gain accuracy from considerably increased depth.

On the ImageNet dataset we evaluate residual nets with depth up to 152 layers—8× deeper than VGG nets but having lower complexity. An ensemble of these residual nets achieves 3.57% error on the ImageNet test set. This result won the 1st place on the ILSVRC 2015 classification task.


## 1. Introduction

Deep convolutional neural networks have led to a series of breakthroughs for image classification. Deep networks naturally integrate low/mid/high-level features and classifiers in an end-to-end multi-layer fashion, and the "levels" of features can be enriched by the number of stacked layers (depth).

Driven by the significance of depth, a question arises: Is learning better networks as easy as stacking more layers?

An obstacle to answering this question was the notorious problem of vanishing/exploding gradients, which hamper convergence from the beginning. This problem, however, has been largely addressed by normalized initialization and intermediate normalization layers.

When deeper networks are able to start converging, a degradation problem has been exposed: with the network depth increasing, accuracy gets saturated (which might be unsurprising) and then degrades rapidly. Unexpectedly, such degradation is not caused by overfitting, and adding more layers to a suitably deep model leads to higher training error.

The degradation problem suggests that all systems are not similarly easy to optimize. Let us consider a shallower architecture and its deeper counterpart that adds more layers to it. There exists a solution by construction to the deeper model: the added layers are identity mappings. The existence of this constructed solution indicates that a deeper model should produce no higher training error than its shallower counterpart. But experiments show that our current solvers on hand are unable to find solutions that are comparably good or better than the constructed solution.

In this paper, we address the degradation problem by introducing a deep residual learning framework.


## 2. Deep Residual Learning

### 2.1 Residual Learning

Instead of hoping each stack of layers directly fits a desired underlying mapping H(x), we explicitly let these layers fit a residual mapping F(x) := H(x) − x. The original mapping is recast into F(x) + x.

We hypothesize that it is easier to optimize the residual mapping than to optimize the original, unreferenced mapping. To the extreme, if an identity mapping were optimal, it would be easier to push the residual to zero than to fit an identity mapping by a stack of nonlinear layers.

### 2.2 Identity Shortcut Connections

The formulation of F(x) + x can be realized by feedforward neural networks with "shortcut connections" (also called skip connections). Shortcut connections are those skipping one or more layers. In our case, the shortcut connections simply perform identity mapping, and their outputs are added to the outputs of the stacked layers:

    y = F(x, {W_i}) + x

where x and y are the input and output vectors of the layers considered. The function F(x, {W_i}) represents the residual mapping to be learned.

The shortcut connections introduce neither extra parameter nor computation complexity. We can fairly compare plain and residual networks that simultaneously have the same number of parameters, depth, width, and computational cost.

### 2.3 Why Residuals Help: The Vanishing Gradient Problem

The vanishing gradient problem occurs when gradients become extremely small as they are backpropagated through many layers, making it difficult for earlier layers to learn. It is particularly problematic for deep networks and was a key motivation for LSTMs and residual connections.

Residual connections directly address the vanishing gradient problem by providing a gradient highway: the identity shortcut allows gradients to flow directly from the loss to any layer, bypassing the problematic multiplication chain that causes them to vanish.

During backpropagation, the gradient of the residual block is:

    ∂L/∂x = ∂L/∂y * (1 + ∂F/∂x)

The "+1" term ensures the gradient never completely vanishes, as it always has at least an identity component.


## 3. Network Architectures

### 3.1 Plain Networks (Baseline)

Our plain baselines are mainly inspired by the philosophy of VGG nets. The convolutional layers mostly have 3×3 filters and follow two simple design rules:
1. For the same output feature map size, the layers have the same number of filters.
2. If the feature map size is halved, the number of filters is doubled to preserve the time complexity per layer.

### 3.2 Residual Networks

Based on the plain networks, we insert shortcut connections that turn the plain network into its residual version. The identity shortcuts can be directly used when the input and output are of the same dimensions.

When the dimensions change, we consider two options:
(A) Perform identity shortcut with extra zero entries padded for increasing dimensions.
(B) The projection shortcut: 1×1 convolutions to match dimensions.

### 3.3 Batch Normalization

We adopt batch normalization (BN) after each convolutional layer and before activation. Batch normalization normalizes the activations of each layer across a mini-batch, reducing internal covariate shift.

Batch normalization helps stabilize and speed up training, allows higher learning rates, and acts as a regularizer. We do not use dropout, following the practice in recent studies.

### 3.4 Network Depths

We test ResNets with 18, 34, 50, 101, and 152 layers. For networks deeper than 34 layers, we use a bottleneck design to reduce training time: we replace the two 3×3 layers with a 1×1 → 3×3 → 1×1 stack.


## 4. Experiments

### 4.1 ImageNet Classification

We evaluate our method on the ILSVRC 2015 classification task using 1.28 million training images and 50k validation images of 1000 classes.

ResNet-34 vs. plain-34:
- Plain-34 has higher training error than plain-18 (degradation problem)
- ResNet-34 reduces training error by 3.5% compared to its plain counterpart
- ResNet-34 achieves lower validation error than the 18-layer counterpart, demonstrating the benefit of depth

ResNet-152:
- Single-model top-5 error: 4.49%
- Ensemble: 3.57% top-5 error on ImageNet test set
- Won 1st place in ILSVRC 2015


### 4.2 CIFAR-10 Experiments

We also explored architectures with more than 1000 layers on CIFAR-10. Networks with 110 layers exhibit slightly higher error rates than the 20-layer baseline due to overfitting. With aggressive data augmentation, deep ResNets generalize well.


## 5. Object Detection

ResNets significantly improve detection performance on PASCAL VOC and MS COCO. Using ResNet-101 as the backbone for Faster R-CNN:
- PASCAL VOC 2007: 76.4% mAP
- MS COCO: 21.9% mAP

These results demonstrate that residual learning is broadly applicable beyond classification.


## 6. Conclusion

We presented a residual learning framework for training very deep neural networks. Residual networks are easier to optimize, and achieve higher accuracy with increased depth. On the ImageNet dataset, extremely deep residual nets (152 layers) achieved state-of-the-art results.

Residual connections are now a fundamental component of modern deep learning architectures, used in transformers (attention sub-layers have residual connections), U-Nets, and virtually every state-of-the-art architecture.


## Key Concepts

### Gradient Descent and Optimization

Gradient descent is an optimization algorithm that iteratively adjusts model parameters in the direction opposite to the gradient of the loss function. It minimizes the loss by taking small steps proportional to the negative gradient.

Variants:
- **Stochastic Gradient Descent (SGD)**: updates using a single sample at a time
- **Mini-batch gradient descent**: updates using a small batch (most common in practice)
- **Adam**: adaptive learning rate optimizer combining momentum and RMSProp
- **Learning rate schedules**: cosine annealing, warm restarts, linear warmup

### Batch Normalization

Batch normalization (Ioffe & Szegedy, 2015) normalizes the activations of each layer across a mini-batch:

    BN(x) = gamma * (x - mean) / sqrt(variance + epsilon) + beta

Benefits:
- Reduces internal covariate shift
- Stabilizes and speeds up training
- Allows higher learning rates
- Acts as regularizer (reduces need for dropout)
- Makes optimization landscape smoother

### Dropout Regularization

Dropout is a regularization technique where randomly selected neurons are ignored during training with a probability p (the dropout rate). This prevents co-adaptation of neurons and acts as an ensemble method, reducing overfitting.

During training, each neuron is set to zero with probability p. During inference, all neurons are active but scaled by (1-p) to account for the expected scaling.

Dropout was proposed by Srivastava et al. (2014) and was widely used before batch normalization became standard. In ResNets (and most modern architectures), batch normalization largely replaces dropout.

### Softmax Function

The softmax function converts a vector of raw scores (logits) into a probability distribution by exponentiating each score and dividing by the sum of all exponentiated scores:

    softmax(z_i) = exp(z_i) / sum(exp(z_j) for all j)

The softmax function is used in:
- The output layer of classification models (converts logits to class probabilities)
- The attention mechanism in Transformers (Scaled Dot-Product Attention)
- Language model outputs (probability distribution over vocabulary)

Properties:
- All outputs are positive
- All outputs sum to 1.0
- Emphasizes the largest value (near one-hot for large inputs)

### Convolutional Neural Networks (CNNs)

Convolutional layers apply learned filters to the input, detecting features like edges, textures, and shapes in images. Key properties:
- Weight sharing: the same filter is applied across all positions
- Local connectivity: each output unit sees only a local region of the input
- Translation equivariance: features can be detected regardless of position

VGG-16: 16-layer network using 3×3 convolutions throughout; very deep but no shortcut connections.
ResNet-50: 50-layer residual network; significantly easier to train than plain VGG-style deep networks.


## Historical Context and Related Work

### The Vanishing Gradient Problem (Historical)

The vanishing gradient problem was identified in the early 1990s by Hochreiter (1991) and Bengio et al. (1994). It explains why deep networks trained with backpropagation struggle: gradients must be multiplied through many layers, and if the gradients are consistently less than 1, they shrink exponentially with depth.

Solutions developed over the years:
1. **LSTMs (1997)**: gating mechanisms that preserve gradients over long sequences
2. **ReLU activations (2010s)**: replaced sigmoid/tanh, partially addressing vanishing gradients
3. **Careful initialization (2010s)**: Xavier, He initialization
4. **Batch normalization (2015)**: stabilizes activations
5. **Residual connections (2015, this paper)**: provides gradient highway

### Highway Networks (Srivastava et al., 2015)

Concurrent work to ResNets. Highway networks use learned gating functions to control information flow, rather than simple identity shortcuts. ResNets proved simpler and more effective.

### DenseNets (Huang et al., 2017)

Extension of residual connections where each layer is connected to every subsequent layer, creating a dense connection pattern. More parameter-efficient than ResNets for certain applications.
